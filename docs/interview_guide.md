# Week 1 user session

Use fictional contacts and places. Ask permission before recording audio.
Record observations with anonymous participant IDs such as P01.

Ask:
1. Describe the most recent voice-assistant mistake you remember.
2. What were you trying to do?
3. Did you repeat yourself, use the screen, or give up?
4. For which mistakes would an extra confirmation be worthwhile?

Then let the participant express 10 tasks naturally:
- Contact a uniquely named person.
- Contact Alex without specifying which Alex.
- Contact the Alex from the school project.
- Change the intended contact mid-utterance.
- Cancel a queued call.
- Navigate to a uniquely named place.
- Refer to one of two Starbucks locations.
- Change the destination mid-utterance.
- Select one of two songs named Hello.
- Resume music with no selected track.

Record:
task, wording, expected result, model behavior, extra turns, user preference.

Do not read the expected wording aloud for the participant to repeat.
